# ARGUS

ARGUS is an ongoing research project exploring how AI agents can translate natural language requests into Linux shell commands while evaluating the risks involved.

The focus is on building a governance layer that can identify potentially harmful commands, handle approvals, and study how safety mechanisms respond to ambiguous and adversarial prompts.

The project is in its early stages, with initial research, benchmark development, baseline testing, and UI mockups underway.

More updates will follow as the research and implementation progress.
